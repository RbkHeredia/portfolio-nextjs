# Portafolio Personal

Este es el código fuente de mi portafolio personal, desarrollado con **Next.js** y estilizado con **TailwindCSS** y **NextUI**. El proyecto está diseñado para mostrar mis habilidades, experiencia y proyectos como desarrolladora web.

## Tecnologías utilizadas

- **Next.js** (Framework de React para aplicaciones web)
- **React** (Librería de JavaScript para interfaces de usuario)
- **TailwindCSS** (Framework CSS para estilos rápidos y eficientes)
- **NextUI** (Componentes de UI optimizados para Next.js)
- **Framer Motion** (Animaciones en React)
- **FontAwesome** (Íconos para mejorar la presentación visual)

## Instalación y ejecución

1. Clona este repositorio:

   ```sh
   git clone https://github.com/tu-usuario/portfolio.git
   cd portfolio
   ```

2. Instala las dependencias:

   ```sh
   npm install
   ```

3. Ejecuta el entorno de desarrollo:

   ```sh
   npm run dev
   ```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el proyecto.

## Scripts disponibles

- `npm run dev` - Inicia el servidor de desarrollo.
- `npm run build` - Construye la aplicación para producción.
- `npm run start` - Inicia la aplicación en modo producción.
- `npm run lint` - Ejecuta el linter para verificar errores en el código.



## Características del portafolio

- Diseño responsivo y moderno.
- Sección de proyectos destacados.
- Información sobre experiencia y habilidades.
- Contacto y enlaces a redes sociales.
- Animaciones fluidas con Framer Motion.
